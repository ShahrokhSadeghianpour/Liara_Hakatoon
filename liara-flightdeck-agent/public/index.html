                        دستور خودکار انتشار سورس‌کد (Zero-Config Release):
                    

                    

                        زیرساخت و متغیرهای محیطی شما در لیارا آماده شده‌اند. برای ارسال فایل‌های سورس‌کد از سیستم خود یا CI/CD گیت‌هاب، کافیست دستور زیر را اجرا کنید:
                    

                    

                        npx @liara/cli deploy --app my-shop-app --port 3000
                        
                    

                

            


            
            

                

                    

                        
                    

                    

                        
اتصال دامنه شخصی و راهنمای گام‌به‌گام ایرنیک (IRNIC)

                        
ثبت دامنه در لیارا با API + راهنمای تنظیم DNS خارج از دسترس API

                    

                


                

                    
                    
                


                

                    

                        
                        اعلام محدودیت API: پنل ایرنیک (nic.ir) فاقد API عمومی برای تغییر خودکار NameServer است.
                    

                    

                        دامنه شما توسط ایجنت در لیارا ثبت شد (POST /v1/domains). اکنون فقط این ۲ مرحله کوتاه را در پنل ایرنیک انجام دهید:
                        
۱. وارد پنل ایرنیک شوید و از بخش «دامنه‌های من» روی «ویرایش ردیف‌های کارگزار نام» کلیک کنید.
                        
۲. دو کارگزار نام زیر را کپی و در ایرنیک ثبت کنید:
                    

                    

                        

                            ns1.liara.zone
                            
                        

                        

                            ns2.liara.zone
