                    گام دوم از ۴ • نیازمند تایید شما (Human-in-the-Loop)
                
                
پیشنهاد زیرساخت لیارا برای پروژه شما

                

                    بر اساس بررسی کدهای شما، تنظیمات زیر پیشنهاد می‌شود. دستیار بدون اجازه شما هیچ هزینه‌ای ایجاد نمی‌کند؛ موارد را بررسی و تایید کنید.
                

            


            

                
                
                

                    

                        
                        
                        
آدرس سایت شما: https://my-shop-app.liara.run

                    


                    

                        
                        
                    

                


                
                

                    

                        
                        بهترین توازن قیمت و کارایی
                    


                    

                    

                        💡 چرا این پلن؟ پروژه شما برای اجرای بدون کندی و مدیریت پردازش‌های هم‌زمان به حداقل ۱ گیگابایت رم نیاز دارد تا با خطای کمبود حافظه مواجه نشود.
                    

                


                
                

                    

                        
                        
                    

                    

                        
                    

                


                
                

                    
                    

                        نکته شفاف درباره شارژ حساب (محدودیت API):
                        عملیات پرداخت بانکی (شاپرک) به دلایل امنیتی از طریق API قابل انجام خودکار نیست. پیش از تایید ساخت برنامه، مطمئن شوید کیف پول لیارای شما شارژ کافی دارد (صفحه افزایش اعتبار لیارا).
                    

                


                
                

                    

                        
                        تایید نهایی شما پیش از اجرای عملیات در لیارا (Human-in-the-Loop)
                    

                    

                        با کلیک روی دکمه تایید، دستیار درخواست ساخت برنامه (POST /v1/projects) و تنظیم متغیرهای محیطی (POST /v1/projects/{app}/update-envs) را به حساب لیارای شما ارسال می‌کند.
                    

                    

                        
                        
                    

                

            

        


        
        
        
        

            

                
                    گام سوم از ۴ • استقرار و اتصال دامنه
                
                
وضعیت راه‌اندازی سرویس و تنظیم دامنه

                

                    مراحل راه‌اندازی زیرساخت شما در لیارا انجام شد. در این بخش می‌توانید وضعیت استقرار و راهنمای گام‌به‌گام اتصال دامنه ایرنیک را مشاهده کنید.
                

            


            
            

                

                    

                        
آدرس پیش‌فرض سرویس شما در لیارا:

                        
                            https://my-shop-app.liara.run
                            
                        
                    

                    
                        آماده بهره‌برداری
                    
                


                
                

                    
                


                
                

                    

                        
                        نحوه ارسال نهایی سورس‌کد (در صورت تغییر کدها):
                    

                    

                        برنامه و متغیرهای محیطی شما در لیارا ساخته شدند. برای آپلود مستقیم کل پوشه کدهای خود یا اتصال به گیت‌هاب، می‌توانید از دستور تک‌خطی زیر در ترمینال سیستم خود نیز استفاده کنید:
                    

                    

                        npx @liara/cli deploy --app my-shop-app --port 3000
                        
                    

                

            


            
            

                

                    

                        

                            
                        

                        

                            
راهنمای اتصال دامنه شخصی (ایرنیک / کلودفلر)

                            
ثبت دامنه در لیارا با API + راهنمای کپی رکوردها برای پنل ایرنیک

                        

                    

                


                

                    
                    
                


                

                    

                        دامنه در لیارا ثبت شد. از آنجا که پنل ایرنیک (nic.ir) فاقد API عمومی است، لطفاً وارد حساب ایرنیک یا DNS خود شوید و دو کارگزار نام (NameServer) زیر را کپی و جایگزین کنید:
                    

                    

                        

                            ns1.liara.zone
                            
                        

                        

                            ns2.liara.zone
                            
                        

                    

                


                

                    
                

            

        


        
        
        
        

            

                
                    گام چهارم از ۴ • مهندس قابلیت اطمینان سایت (SRE Agent)
                
                
پایش سلامت سرویس و عیب‌یابی هوشمند

                

                    در این بخش دستیار هوشمند وضعیت مصرف منابع و لاگ‌های سرویس شما را بررسی می‌کند و در صورت بروز کندی یا خطای HTTP 500، علت ریشه‌ای را پیدا و با اجازه شما برطرف می‌کند.
                

            


            
            

                
                
                

                    

                        سرویس انتخاب‌شده:

Latency: 115 ms

                    


                    

                        

                            مصرف پردازنده (CPU)
                            22%
                        

                        

                            

                        

                    


                    

                        

                            مصرف حافظه (RAM)
                            45% (460 MB)
