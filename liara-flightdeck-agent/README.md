# 🚀 Liara FlightDeck | دستیار هوشمند راه‌اندازی، دیپلوی و مهندس SRE لیارا

این پروژه یک **AI DevOps & SRE Agent** به همراه **MCP Server** است که عملیات پیچیده زیرساختی در پلتفرم ابری **لیارا (Liara PaaS)** را به یک تجربه کاربری (UX) ساده، گام‌به‌گام و ایمن با رعایت اصل **Human-in-the-Loop** تبدیل می‌کند.

## ۱. معماری سیستم (Architecture)
سیستم از ۳ لایه یکپارچه تشکیل شده است:
1. **رابط کاربری هوشمند (Progressive Disclosure Web UI):** طراحی‌شده در ۴ گام شفاف (کالبدشکافی کد -> پیشنهاد و تایید انسانی -> دیپلوی و دامنه ایرنیک -> پایش و عیب‌یابی خودکار SRE) به همراه پنل چت همکار هوشمند و لاگ زنده API.
2. **سرور بک‌اند پراکسی (`server.js`):** مبتنی بر Node.js و Express برای مدیریت ایمن درخواست‌های REST API به `https://api.liara.ir` (رفع کامل محدودیت CORS مرورگر) و ارتباط با مدل زبانی هوشمند (`gpt-6-luna`).
3. **سرور استاندارد MCP (`mcp-server.js`):** پیاده‌سازی پروتکل Model Context Protocol برای اتصال مستقیم ابزارهای لیارا به ادیتورهای هوشمند کد (Cursor, Claude Desktop, VSCode).

## ۲. نحوه اتصال به APIهای لیارا
این دستیار از طریق هدر `Authorization: Bearer <LIARA_TOKEN>` به اندپوینت‌های رسمی زیر متصل می‌شود:
- `GET /v1/projects`: دریافت لیست سرویس‌ها و وضعیت سلامت.
- `POST /v1/projects`: ساخت برنامه جدید با پلتفرم و پلن بهینه (پس از تایید کاربر).
- `POST /v1/projects/{app}/update-envs`: تزریق خودکار متغیرهای محیطی استخراج‌شده از پروژه.
- `POST /v1/domains`: ثبت دامنه شخصی برای پروژه.
- `GET /v1/projects/{app}/logs`: استخراج آخرین لاگ‌های اجرایی سرویس برای موتور عیب‌یاب SRE.
- `POST /v1/projects/{app}/actions/restart`: ری‌استارت امن سرویس پس از اعمال اقدامات اصلاحی.

## ۳. مدیریت تعامل امن با کاربر (Human-in-the-Loop)
ایجنت عملیات‌ها را به دو دسته تقسیم می‌کند:
- **عملیات کم‌ریسک (اجرای خودکار):** خواندن فایل‌های پروژه (`package.json`, `requirements.txt`, `Dockerfile`)، تشخیص پورت و پلتفرم، تولید فایل `liara.json` و خواندن لاگ‌ها.
- **عملیات حساس و هزینه‌بر (توقف برای اخذ تایید کاربر):** ساخت پروژه و تخصیص پلن سخت‌افزاری، تغییر متغیرهای محیطی، تغییر پلن و ری‌استارت سرویس در زمان بحران SRE.

## ۴. شفافیت در محدودیت‌های API
1. **شارژ کیف پول (درگاه بانکی شاپرک):** به دلایل امنیتی بانکی، شارژ حساب از طریق API امکان‌پذیر نیست و دستیار پیش از ساخت پروژه، لینک مستقیم و هشدار بررسی اعتبار کیف پول را به کاربر نمایش می‌دهد.
2. **تغییر کارگزار نام در ایرنیک (`nic.ir`):** از آنجا که سامانه ایرنیک فاقد API عمومی برای تغییر خودکار رکوردهای NS است، دستیار دامنه را از طریق API در لیارا ثبت کرده و رکوردهای `ns1.liara.zone` و `ns2.liara.zone` را با دکمه کپی سریع و راهنمای گام‌به‌گام در اختیار کاربر می‌گذارد.
